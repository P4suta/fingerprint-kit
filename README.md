# Fingerprint-kit

Experimental fingerprint enrollment and verification in Rust.

## Installation

```sh
git clone https://github.com/P4suta/fingerprint-kit.git
cd fingerprint-kit
cargo build --locked --release
```

## Usage

```sh
cargo run --locked --release -- demo
```
