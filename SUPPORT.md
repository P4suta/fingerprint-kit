# Support

Use GitHub Issues for reproducible bugs and scoped feature requests. Include the project version,
platform, minimal commands, and synthetic inputs needed to reproduce the behavior.

This project does not provide support for real fingerprint devices, OS login, production
authentication, deployment, biometric policy decisions, or fprint/libfprint/fprintd compatibility.
Do not post real biometric data or sensitive artifacts. Report vulnerabilities privately as
described in [SECURITY.md](SECURITY.md).
